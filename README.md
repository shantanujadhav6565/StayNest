# 🏡 StayNest

StayNest is a full-stack Airbnb-inspired web application where users can explore, create, edit, and manage property listings. The project includes secure authentication, authorization, reviews, and a responsive user interface.

## 🚀 Features

- 🔐 User Authentication (Sign Up, Login & Logout)
- 🛡️ Authorization (Only listing owners can edit or delete their listings)
- 🏠 Create, Edit, View & Delete Listings
- 📍 Property Details with Location
- 🖼️ Image Support
- ⭐ Reviews & Ratings
- 👤 Review Author Information
- 💬 Flash Messages
- 📱 Responsive User Interface

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/shantanujadhav6565/StayNest.git
```

### Navigate to the project folder

```bash
cd StayNest
```

### Install dependencies

```bash
npm install
```

### Start the server

```bash
npm start
```

Open your browser and visit:

```text
http://localhost:8080
```
